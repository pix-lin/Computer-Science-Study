## 📝 스터디 규칙 & 가이드 (Rules & Guide)

### 📋 규칙
1. 매주 월요일까지 각자 공부한 내용을 **Issue**에 등록합니다.
2. 공부한 내용은 각자 **Branch**를 생성하여 작업 후 **PR(Pull Request)**을 보냅니다.
3. PR 승인이 완료되면 `main` 브랜치로 Merge 됩니다.
